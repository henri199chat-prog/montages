# هدية @aymen.ai.lab: أول Skill جاهزة 🎁

**كاتب الكابشن العربي**: مهارة تخلّي Claude يكتب لك كابشن Instagram بالعربي البسيط، بنفس القواعد في كل مرة.

## كيف تستعملها

**في Claude.ai**
1. نزّل المجلد `arabic-caption-writer` واضغطه ملف ZIP.
2. افتح Claude ← الإعدادات ← Capabilities ← Skills، وارفع الملف.
3. اكتب: «اكتب كابشن لريل عن ...».

**في Claude Code**
انسخ المجلد إلى `~/.claude/skills/` وبعدها اطلب كابشن، أو اكتب `/arabic-caption-writer`.

**بدون أي إعداد**
افتح ملف `SKILL.md`، انسخ محتواه في أول رسالة لـ Claude، وبعدها اطلب الكابشن.

## عدّلها على مقاسك

افتح `SKILL.md` وغيّر القواعد: لهجتك، عدد الهاشتاقات، الإيموجي. هذا هو سر الـ Skills: تكتب طريقتك مرة وحدة، وClaude يرجع لها كل مرة.

تابع @aymen.ai.lab — الحلقة الجاية نبني Skill ثانية من الصفر خطوة بخطوة.
