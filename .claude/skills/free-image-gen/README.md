# سكل الصور المجانية لـ Claude Code 🎨

خلّ Claude Code يولّد صور من حسابك في ChatGPT أو Gemini، بدون API وبدون ما تدفع شي.

## شنو تحتاج
1. **Claude Code**
2. **إضافة Claude in Chrome**: https://claude.ai/chrome
3. حساب **ChatGPT** أو **Gemini** (المجاني يكفي) ومسجّل دخول فيه على كروم

## التثبيت
فك الضغط، وحط مجلد `free-image-gen` هني:

```
~/.claude/skills/free-image-gen/
```

أو انسخه بهالأمر من مكان الملف:

```bash
mkdir -p ~/.claude/skills && cp -R free-image-gen ~/.claude/skills/
```

بعدها سكّر Claude Code وافتحه من جديد.

## الاستخدام
قول لـ Claude بس:
- «سو لي صورة خلفية للريل عن الذكاء الاصطناعي»
- «صمم ثمبنيل لهالفيديو»
- «ولّد صورة منتج لـ…»

Claude بيفتح كروم، يكتب البرومبت، يولّد الصورة، يحمّلها، ويستخدمها في شغلك على طول.

## ملاحظات
- إذا خلص الحد المجاني في ChatGPT، يحوّل على Gemini بروحه.
- ما يسجّل دخول بدالك، وما يضغط على أي زر اشتراك أو دفع.
- النص العربي داخل الصور يطلع خربان، فالأفضل تضيفه بالمونتاج.
