# SAM Content OS — مهارة صناعة ريلز انستقرام على Claude

مهارة (Skill) لـ Claude تشتغل كمدير محتوى شخصي لريلز انستقرام. تعطيها **موضوع بس**، وتطلع لك حزمة كاملة جاهزة للتسجيل:

- 🎯 **الهوك** + نص الكفر
- 🎙️ **السكريبت** كامل بلهجتك (الكويتي افتراضياً) مع المدة المتوقعة
- 📝 **الكابشن** جاهز للنسخ
- 🎬 **دليل المونتاج** + الكلام اللي يطلع على الشاشة
- 👉 **CTA** واحد مناسب للمحتوى
- 📊 **تقييم من 100** مع نقاط القوة والضعف
- 🧠 **سجل مواضيع** عشان ما تتكرر أفكارك
- ✂️ **ملخص للمونتير** إذا عندك أحد يمنتج لك

وكل شي تراجعه قبل النشر… والقرار دايم بيدك.

---

## طريقة التثبيت

### على Claude.ai أو تطبيق Claude
1. نزّل ملف [`sam-content-os.skill`](./sam-content-os.skill) من هالصفحة (اضغط عليه ثم زر التنزيل).
2. افتح Claude ← **Settings** ← **Capabilities** ← **Skills**.
3. اضغط **Upload skill** واختر الملف.
4. فعّل المهارة، وافتح محادثة جديدة واكتب موضوع الريل.

### على Claude Code
انسخ مجلد `sam-content-os` إلى:
```
~/.claude/skills/
```
